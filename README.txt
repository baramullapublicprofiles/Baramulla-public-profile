BARAMULLA PUBLIC PROFILES — BIOGRAPHICAL VERSION

This package contains:
- index.html: the website, with embedded profile data fallback.
- data/profile.json: editable profile biography and activity timeline.
- assets/profile-photo.jpg: supplied profile photograph.
- README.txt: publishing and editing notes.

UPLOAD TO THE ROOT OF THE EXISTING REPOSITORY:
https://github.com/baramullapublicprofiles/Baramulla-public-profile

The repository root should contain index.html, README.txt, data/profile.json and assets/profile-photo.jpg.

To publish:
1. Extract this ZIP on your Mac.
2. In the existing GitHub repository, choose Add file -> Upload files.
3. Upload index.html, README.txt and the data and assets folders.
4. Commit to main and wait for the Pages deployment to finish.
5. Hard-refresh the website with Command+Shift+R.

To edit the biography:
Edit data/profile.json on GitHub. The website also contains an embedded fallback copy of the profile data to avoid a blank page if the JSON fetch fails. When making substantial edits, keep both copies in sync; a refreshed package can be generated after content changes.

The writing is presented as a third-person biography. Do not invent precise attendance figures, expenditure or personal funding claims. Add the confirmed public Facebook profile URL to subject.facebook_profile when available.
